Portfolio

  • The MISSI

    Software Development

    Project Overview

    The MISSI (Multi-Instrumented Stroke Simulation Interface) is a finalist project developed to help beginner sprint-canoe athletes improve stroke consistency and synchronization. The system combines motion tracking, visual cues, and real-time feedback to guide users toward smoother, more coordinated paddling technique.

    MISSI provides a fully interactive training experience: athletes can monitor their stroke rate, track their paddle position, and receive rhythm-based visual and audio guidance designed to reinforce proper timing. The platform also supports group activity tracking, customizable sync speed, and a realistic canoeing environment for immersive practice.

    The goal of the project was to create a beginner-friendly, accessible tool that bridges biomechanics, human-computer interaction, and web-based simulation. MISSI emphasizes usability, performance feedback, and athlete engagement—helping new paddlers develop confidence while training efficiently.

    Technologies Used

    • JavaScript (Frontend Interaction)
    • Web-based Motion Tracking
    • Real-time Sync & Feedback Engine
    • UI/UX Interface Design
    • Immersive Multimedia Integration

  • Toronto Shelter Data Visualization

    Data Science

    Project Overview

    This project visualizes key insights from Toronto’s homeless shelter system, focusing on how far individuals must travel to access available beds. Using real city data, our team built an interactive, story-driven slide deck that highlights the scale of homelessness, travel burdens across neighbourhoods, and capacity gaps in high-demand areas. The goal was to present the findings in a way that feels human, accessible, and grounded in the lived experience behind the numbers.

  • TrendBaker

    Software Development

    Project Overview

    TrendBaker is an evidence-first bakery trend discovery MVP built for FGF Brands at a hackathon. It discovers repeated product-intent signals from official APIs like YouTube, validates the strongest candidates with a targeted second pass, and computes deterministic momentum and confidence scores rather than letting an LLM guess numbers.

    Every recommendation is attached to collected evidence: an optional OpenAI-compatible LLM layer only canonicalizes and explains findings, never scores them. Results are exported as auditable JSON and surfaced in a four-view Streamlit dashboard covering trend quadrants, ingredient and product-format opportunities, and full trend detail with clickable evidence.

    Technologies Used

    • Python (data pipeline, deterministic scoring)
    • YouTube Data API v3 & Reddit Data API
    • OpenAI-compatible LLM (Claude API) for evidence-grounded synthesis
    • SQLite & atomic JSON exports
    • Streamlit dashboard
    • React/Vite dashboard (optional companion app)

  • InContent

    Software Development

    Project Overview

    InContent scores a TikTok draft before it's posted and returns prioritized, specific edit suggestions — catching what's fixable before it goes out, not after. Editing mechanics like cuts, silence, and speech rate are computed deterministically with no model call, while only genuinely subjective judgment, such as whether a hook creates a curiosity gap or a caption lands, goes through a multimodal LLM.

    Independently testable skills handle ingestion, transcription, pacing, hook mechanics, trend context, semantic analysis, and scoring, wired together by a single orchestrator and served through a FastAPI backend with a web dashboard that takes a draft from upload straight to a breakdown of ranked, specific fixes.

    Technologies Used

    • Python & FastAPI
    • Speech-to-text with word-level timestamps
    • Scene-cut & audio envelope analysis (ffmpeg)
    • Anthropic Claude API (multimodal semantic scoring)
    • Playwright (TikTok Creative Center trend scraping)
    • Perplexity & Google Trends APIs (trend context)

  • PartSelect Parts Assistant

    Software Development

    Project Overview

    A scoped AI chat agent built for PartSelect, covering refrigerator and dishwasher parts only. A fast keyword-based scope guard deflects out-of-scope questions before ever hitting the LLM, then a Claude Haiku router classifies intent and appliance before handing off to one of three specialist LangGraph agents for parts lookup, repair guidance, or order support.

    Each specialist agent is a LangGraph createReactAgent with tool access to live PartSelect data scraped on demand, streamed back to the UI over Server-Sent Events. Every query costs just two Claude API calls — router plus specialist worker — keeping per-query cost to roughly $0.001–0.003 with Haiku.

    Technologies Used

    • Next.js 14 (App Router)
    • LangGraph multi-agent orchestration
    • Claude Haiku (Anthropic API)
    • Server-Sent Events (streaming)
    • Cheerio web scraping against partselect.com
    • Zod-validated LangChain tools

  • Cosailor Insights

    Software Development

    Project Overview

    Cosailor Insights is an AI-scored roofing lead dashboard: given a zip code and radius, it surfaces GAF-certified contractors ranked by a computed priority score, plots them on a map, and gives each one a grounded, plain-English summary and talking points a sales rep can use before dialing.

    A FastAPI backend runs the ingestion pipeline — scrape, enrich with Perplexity Sonar research, score, then narrate with a single-shot Claude call per lead — and guards the model against inventing facts by instructing it to use only the already-known, already-scored fields it's given. The score itself is always computed deterministically, never by the LLM. A React + Leaflet frontend renders the ranked list alongside an interactive map of every lead.

    Technologies Used

    • FastAPI & SQLAlchemy (Python backend)
    • Anthropic Claude API (grounded lead narration)
    • Perplexity Sonar (contractor research)
    • React, TanStack Query & Leaflet (frontend)
    • Vite & Tailwind CSS
    • SQLite
